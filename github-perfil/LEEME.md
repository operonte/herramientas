# Cómo publicar el README de perfil y la bio en GitHub

1. **README de perfil:** crea un repositorio **público** llamado exactamente `operonte` (igual a tu usuario),
   marca "Add a README" y pega el contenido de `README.md` de esta carpeta. GitHub lo muestra en tu perfil.
2. **Bio** (Settings → Profile → Bio; máx. 160 caracteres). Propuesta (~120 caracteres):

   `Páginas web, apps y bases de datos para negocios en Chile · Flutter · Supabase · Firebase · Freelance y contrato`

3. **Sitio web del perfil:** `https://cristianbravo-dev.web.app`. **Ubicación:** Chile.
4. **Repos fijados** (Customize your pins), los que mejor cuentan tu historia:
   Bitácora, PrecioBencina, HolyApp, Control de Rondas, Control de Acceso y sbox.
5. Revisa que cada repo fijado tenga capturas y una descripción corta ("About") con su enlace.
